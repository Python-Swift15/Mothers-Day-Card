# Mother’s Day Card 💐💖

A beautifully animated digital Mother’s Day greeting built with Python Turtle. The project generates a colorful bouquet scene with flowers, stars, and animated hearts to create a heartfelt visual message.

This project combines graphics, animation, and creative coding to produce a moving celebratory card.

## Features

- 💐 Fully drawn animated flower bouquet
- 💖 Pulsing and moving hearts animation
- ⭐ Random twinkling star background
- ✍️ Custom “Happy Mother’s Day” text display
- 🎨 Multi-color visual design using Turtle graphics
- 🔁 Continuous smooth animation loop

## Requirements

- Python 3.x

## Installation

```bash
git clone https://github.com/your-username/motherday.git
cd motherday
```

## Usage

```bash
python3 PY3motherday.py
```

## How It Works

* The screen is initialized using Turtle graphics in full canvas mode
* A bouquet of flowers is drawn using coordinate-based positioning
* Stars are randomly generated in the background
* Hearts animate by changing size over time
* The scene updates continuously to create motion effects

## Visual Elements

* 🌸 Centered flower bouquet with stems and petals
* ⭐ Random starfield background
* 💖 Animated hearts that grow and shrink
* 💛 Decorative text elements for presentation

## Technical Details

* Uses turtle graphics for all rendering
* Animation loop controlled with time.sleep()
* Randomized star positioning for dynamic background
* Custom drawing functions for reusable shapes (heart, star, flower)
* Screen updates optimized with screen.tracer(0)
